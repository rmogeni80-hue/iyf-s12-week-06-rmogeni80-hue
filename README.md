# Week 6: Weather Dashboard

A simple weather application built with HTML, CSS, and JavaScript. It fetches live data from the OpenWeatherMap API.

## Features
- Search for a city using the button or the Enter key.
- Displays temperature, weather icon, description, feels like, humidity, wind, and pressure.
- Shows a "Loading..." message while fetching data.
- Handles errors for unknown cities and no internet connection.
- Saves the last 5 searched cities in localStorage.
